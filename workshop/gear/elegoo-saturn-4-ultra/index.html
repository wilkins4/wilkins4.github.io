Workshop role

The current primary resin printer

The Saturn 4 Ultra is the machine used for current resin production, miniature tests, and repeatable profile documentation. The older Saturn 8K remains useful for comparison and overflow, but this is the printer that should receive the most complete settings notes and failure records.

Best fit

  • Miniature batches and detailed gaming pieces.
  • Exposure tests tied to one documented resin blend.
  • Product prototypes that need repeatable results.
  • Comparisons against the older Saturn 8K workflow.

What still matters

  • Resin, temperature, layer height, and support design.
  • Clean release film and a verified build surface.
  • Documenting one changed variable at a time.
  • Separating machine problems from model-preparation problems.

Actual workflow

How it is used

Models are oriented and reviewed in Lychee Slicer, then checked for unsupported islands, weak contact points, suction risks, and crowded placement before export. The Workshop resin mixture uses an ABS-like base with a smaller amount of Tenacious for impact resistance. Every useful profile should record the printer, resin mixture, layer height, room condition, exposure values, model type, and result.

!

Settings are not universal

Published settings should be treated as a documented starting point for the same resin and conditions, not a guarantee for every bottle, room, model, or release film.
