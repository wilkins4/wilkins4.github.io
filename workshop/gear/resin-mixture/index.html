Current working mixture

Rigid detail with a controlled amount of flex

The Workshop currently uses an ABS-like resin as the primary component with roughly ten percent Siraya Tech Tenacious by volume. The goal is not to make the print flexible. The smaller Tenacious component is intended to reduce brittle failures on thin weapons, spikes, claws, and gaming pieces that receive normal handling.

!

This is a documented starting point

Resin batches, pigments, temperature, machine condition, layer height, and model geometry can change the result. Recalibrate after changing a component instead of assuming one ratio or exposure profile is universal.

ABS-like base

Provides the main body, detail response, and dimensional behavior of the mixture. This remains the dominant component.

Tenacious component

Adds impact resistance and controlled give. More is not automatically better because excessive flex can change support behavior and final part feel.

Recordkeeping

What gets documented

  • Exact resin product names and colors.
  • Approximate mixture ratio and date mixed.
  • Printer, layer height, exposure settings, and room condition.
  • Model type, support source, and failure location.
  • Post-cure method and real handling result.

A useful test includes both fine detail and a thin feature that can be flexed carefully after curing. A visually sharp print that snaps during normal play is not a complete success.
