## Full description

The Workshop Test Plate is a compact calibration and comparison model for miniature and hobby resin printing. It places several feature groups on one 60 x 40 mm plate so you can document what your current printer, resin, exposure, wash, and cure process actually preserves.

The plate includes:

- Raised lines from 0.20 to 1.00 mm
- Recessed grooves from 0.20 to 1.00 mm
- Square posts and recesses from 0.50 to 1.50 mm
- Relief steps of 0.10, 0.40, and 0.80 mm
- Parallel, grid, rivet, and checker texture fields

The download includes the binary STL, editable OpenSCAD source, README, personal-use license, print log CSV, geometry-validation report, and release manifest.

### Digital beta status

Version 0.1.0 has passed digital mesh validation. The STL is watertight, consistently wound, and contains one connected component with nominal 60 x 40 x 2.8 mm bounds.

A complete physical resin print, wash, cure, measurement, and photography pass is still pending. This release is provided as a free beta so early users can test it, report results, and help identify any geometry or documentation changes needed before v1.0.0.

### Suggested first print

- Confirm the slicer imports the model at 60 x 40 mm
- Print feature side up
- Start with 0.05 mm layers and an already functional resin profile
- Keep washing and curing consistent between comparisons
- Change one variable at a time
- Record the result in the included Print-Log.csv

### Feedback requested

Useful feedback includes:

- Printer and exact resin
- Layer height and exposure
- Wash and cure process
- Smallest clean raised line
- Smallest open recessed groove
- Smallest intact post and open recess
- Warping or brittleness
- Clear photographs of successful and failed features

Send feedback to stephen@stephenwilkinson.dev with the subject `Workshop Test Plate v0.1.0 feedback`.
