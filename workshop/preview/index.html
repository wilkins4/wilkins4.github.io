Acceptance checklist

  • Existing portfolio HTML and CSS remain unchanged.
  • Workshop styles load only inside the Workshop directory.
  • All catalog pages share the same structured data source.
  • Search, category, and personal-use filters update without reloads.
  • Mobile navigation is keyboard accessible and closes with Escape.
  • External links open safely and emit an analytics-ready event.
  • Cards expose release, use, affiliate, and verification status.

Deployment

The Workshop is plain HTML, CSS, JavaScript, and SVG. After the branch is merged into the current GitHub Pages repository, it deploys at /workshop/ without a package install or build command.

For a local preview, serve the repository root with python -m http.server 8080 and open http://localhost:8080/workshop/.
