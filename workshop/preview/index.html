Acceptance checklist

  • Existing portfolio HTML and CSS remain unchanged.
  • Workshop code and styling remain inside the Workshop directory.
  • Catalog filters and mobile navigation work without reloads.
  • Every monetized destination will carry a visible disclosure.
  • The Test Plate package is deterministic and hash checked.
  • The STL is watertight, consistently wound, and connected.
  • Physical resin validation remains clearly marked as pending.
  • No payments, customer accounts, or card data are handled here.

Deployment

The Workshop remains plain HTML, CSS, JavaScript, and SVG. Merging the draft pull request into the current GitHub Pages publishing branch deploys it without a package install or build command.

For local review, run python -m http.server 8080 from the repository root and open http://localhost:8080/workshop/preview/.
